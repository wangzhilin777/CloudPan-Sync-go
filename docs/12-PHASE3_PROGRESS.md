# 三期进度记录（Phase 3 Progress）

## 当前已完成

- 已完成控制台第一轮中文化收口，优先修正普通用户首屏能直接看到的标题、按钮、表单标签和提示语。
- 已把授权页、任务预览页中的关键英文标签收口为中文优先表达，例如“网盘源、风控档位、执行模式、风控覆盖、条目”。
- 已把运行按钮、暂停、继续、重试、能力概览、推荐风控等高频操作文案统一为中文。
- 已补充服务启动阶段的中文提示，启动后会输出本地访问地址、局域网提示、数据目录和默认密码风险提示。
- 已开始同步前端相关测试断言，避免出现“界面已改中文但测试仍卡英文”的脱节状态。
- 已为任务向导补上“目标根目录”输入，预览请求、创建任务、按任务重建向导和复制创建参数都会保留该字段。
- 已打通“目标根目录 + 源端相对路径”的后端映射链路，目标端 metadata 预检查与实际上传已使用映射后的目标路径。
- 已补充后端与静态资源测试，覆盖 `targetRoot` 元数据保存、上传路径映射、结果里的源路径保留，以及页面字段渲染。
- 已新增任务向导内嵌目录浏览器第一版，支持按源/目标授权档案浏览目录、返回上级、刷新目录，并回填源根目录与目标根目录。
- 已为目标目录浏览器补上“在当前目录新建文件夹”入口，用于先建目标目录再回填到任务向导。
- 已为目录浏览器补上“当前目录 / 已选目录”状态标记，降低选完目录后难以确认当前选择的问题。
- 已为目录浏览器补上当前路径面包屑导航，支持按目录层级快速跳回上层路径。
