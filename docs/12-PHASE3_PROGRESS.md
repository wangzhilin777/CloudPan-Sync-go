# 三期进度记录（Phase 3 Progress）

## 当前已完成

- 已完成控制台第一轮中文化收口，优先修正普通用户首屏能直接看到的标题、按钮、表单标签和提示语。
- 已把授权页、任务预览页中的关键英文标签收口为中文优先表达，例如“网盘源、风控档位、执行模式、风控覆盖、条目”。
- 已把运行按钮、暂停、继续、重试、能力概览、推荐风控等高频操作文案统一为中文。
- 已补充服务启动阶段的中文提示，启动后会输出本地访问地址、局域网提示、数据目录和默认密码风险提示。
- 已开始同步前端相关测试断言，避免出现“界面已改中文但测试仍卡英文”的脱节状态。
- 已为任务向导补上“目标根目录”输入，预览请求、创建任务、按任务重建向导和复制创建参数都会保留该字段。
- 已打通“目标根目录 + 源端相对路径”的后端映射链路，目标端 metadata 预检查与实际上传已使用映射后的目标路径。
- 已补充后端与静态资源测试，覆盖 `targetRoot` 元数据保存、上传路径映射、结果里的源路径保留，以及页面字段渲染。
- 已新增任务向导内嵌目录浏览器第一版，支持按源/目标授权档案浏览目录、返回上级、刷新目录，并回填源根目录与目标根目录。
- 已为目标目录浏览器补上“在当前目录新建文件夹”入口，用于先建目标目录再回填到任务向导。
- 已为目录浏览器补上“当前目录 / 已选目录”状态标记，降低选完目录后难以确认当前选择的问题。
- 已为目录浏览器补上当前路径面包屑导航，支持按目录层级快速跳回上层路径。
- 已为源目录与目标目录浏览器补上兼容提示和错误引导，在未选网盘源、网盘源不支持目录浏览、缺少稳定目录标识或目录加载失败时，直接提示可验证授权、回到根目录或手动填写路径。
- 已为目录浏览器补上“已选目录自动滚动定位 + 聚焦高亮”，选定目录后会自动滚动到可视区域并短暂强调当前选项，减少长列表里反复查找。
- 已为“选定根目录(JSON)”与“目标根目录”补上手动填写说明，并在目录浏览不受支持时自动改为更直白的降级提示，减少用户卡在路径格式上的情况。
- 已为源目录与目标目录浏览器补上当前层级提示，根目录和非根目录都会直接显示所在层级，减少用户只靠路径字符串判断当前位置的负担。
- 已为目录浏览器补上更清晰的空目录引导：源端空目录会提示可直接使用当前目录，目标端空目录会提示可直接使用当前目录或新建子目录，减少用户停在空列表无从下手的情况。
- 已把 provider 降级态提示改成字段级引导：不支持目录浏览或目录加载失败时，会直接提示去填写“选定根目录(JSON)”或“目标根目录”，减少用户只看到“手动填写路径”却不知道该填哪里的情况。
- 已把目录加载失败提示细化为恢复引导：失败后会直接提示先刷新目录、切回根目录，再失败时改填“选定根目录(JSON)”或“目标根目录”，减少用户只看到错误却不知道怎么恢复的情况。
- 已细化目录操作成功提示：刷新目录、返回上级后会直接显示当前所在源目录或目标目录，减少用户操作成功后还要再靠路径区域确认结果。
- 已细化目录打开成功提示：点击子目录或面包屑后，会直接提示已进入的源目录或目标目录路径，减少用户来回比对路径栏确认是否跳转成功的情况。
- 已细化目录选择结果提示：设为源目录或目标目录后，会直接提示已回填到“选定根目录(JSON)”或“目标根目录”，减少用户选完目录后还要再回头确认字段是否更新的情况。
- 已把目录浏览器“回填结果”区改成更明确的字段摘要，除了显示路径，还会直接显示“已回填到选定根目录(JSON)”或“已回填到目标根目录”，减少用户只靠 toast 判断结果。
- 已细化目录创建结果提示：新建目标目录后会直接提示已进入该目录并回填到“目标根目录”，减少用户再去分别确认“目录是否创建成功”和“目标根目录是否已更新”的来回操作。
- 已把源目录浏览器“使用当前目录 -> 回填选定根目录(JSON)”加入 UI smoke 验收，除了确认 `选定根目录(JSON)` 字段值，还会确认摘要区同步显示“已回填到选定根目录(JSON)：/”，减少源目录回填只改输入框、却漏掉结果提示联动的问题。
- 已把“使用当前目录 -> 回填目标根目录”加入 UI smoke 验收，避免目录选择体验只靠静态文案断言，补上一段真实浏览器交互验证。
- 已把目标目录浏览器“回填结果摘要”加入 UI smoke 联动验收，除了确认 `目标根目录` 字段值，还会确认摘要区同步显示“已回填到目标根目录：/”，减少目录回填只校验输入框、却漏掉界面反馈不同步的问题。
- 已把源目录浏览器真实 smoke 的前置补齐为“先选源授权档案再验收目录回填”，避免测试场景因缺少源授权档案而误判目录选择链路不可用。
- 已优化目标目录创建后的连续操作体验，新建目录后会自动进入该目录并回填为目标目录，减少“创建 -> 刷新 -> 再查找 -> 再选择”的重复步骤。
- 已把任务预览区的推荐原因说明做了首轮中文友好转换，像“多个顶层目录更适合按子树推进”这类英文推荐理由会直接显示为中文，减少小白在创建任务时还要自己翻译建议说明的负担。
- 已把执行模式提示改成“中文解释 + 技术模式名”组合展示，例如“先完整扫描再执行（pre_scan_flat）”和“按目录逐棵推进（leaf_first_lazy）”，减少任务向导里只出现模式 id 让普通用户看不懂的情况。
- 已把目标网盘源洞察卡里的高频英文标签收口为中文，例如“自动补传时段、校准覆盖、校准完成、已覆盖字段、推荐风控档位、恢复预算、预算建议”，减少普通用户在选择目标网盘源时先看到一堆英文说明的阅读负担。
- 已把目标授权档案洞察卡里的 `auth profile riskDefaults` 来源标识收口成“授权档案内置账号默认风控”，并补上中文解释，减少普通用户看到内部实现名词却不知道来源含义的情况。
- 已把目标授权档案洞察卡标题里的授权方式改成“中文解释 + 技术模式名”，例如“手动令牌（manual_token）”，减少普通用户只看到原始授权模式名却不知道是什么意思的情况。
- 已把“已保存授权档案”列表里的原始授权模式名也同步收口成中文解释，例如“手动令牌（manual_token）”，避免详情卡和列表页对同一授权方式出现两套表达。
- 已把“已保存授权档案”列表里的 `Provider / Status / Edit / Validate / Delete / saved / verified / pending` 等直接可见英文收口成中文优先表达，例如“网盘源、状态、编辑、验证授权、删除、已保存（saved）、待校验（pending）、已校验（verified）”，减少普通用户在列表页里中英混杂阅读的负担。
- 已把目标授权档案洞察卡里的 `附加字段 / 命中字段` 收口成更偏用户语言的 `附加配置项 / 已启用字段`，减少普通用户看到实现味过重的字段名却不知道该怎么理解的情况。
- 已把 Provider 卡收口成“默认简版 + 高级信息折叠”形态，首屏默认只展示名称、状态、授权方式、核心能力、推荐风控和授权入口提示，不再一打开就铺满 fallback、冲突策略、风控提示和恢复预算等大段高级信息。
- 已把 Provider 卡里的高频英文标签同步收口成中文表达，例如“兜底策略、冲突策略、风控特征、风控提示、默认风控、账号默认来源、账号默认建议”，减少 Provider 页首屏中英混杂的阅读负担。
